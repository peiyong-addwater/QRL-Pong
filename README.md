# Code Repository for the Paper _"Entanglement Enhances Quantum Agent Performance in Reinforcement Learning"_

This repository contains the code used in the paper _"Entanglement Enhances Quantum Agent Performance in Reinforcement Learning"_ by _Peiyong Wang, Kieran Hymas_ and _James Quach_.

Scripts:

- `main.py` -- the main script to run the experiments with classical-quantum hybrid agents in the paper.
- `benchmarkClassicalBaseline<64|128|256|336|4096>P.py` -- the set of scripts to run the classical baseline agents with different numbers of parameters, which execute the `Pong1PClassicalBaseline<64|128|256|336|4096>P.py` scripts with the corresponding number of parameters.
- `extract_runs_data.py` -- the script to extract the data from the runs of the experiments and save them in a format that can be easily plotted.
- `generate_plots.py` -- the script to generate the training curves in the paper from the extracted data.
- `rep_analysis_pipeline.sh` -- the bash script to run the whole pipeline of analysing the representations generated by the classical and quantum backbones. This bash script executes `obs_collections.py`, `get_reps.py`, `rep_sim_analysis.py` and `plot_csv.py` in sequence to generate the CKA heatmap in the paper.
